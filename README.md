# SMTH Back
Серверная часть проекта **SMTH**

## Установка
0. **Зависимость!** Установить https://github.com/4ashk1n/smth-shared в ту же папку, в которой будет папка с smth-back
1. `git clone https://github.com/4ashk1n/smth-back.git`
2. `cd smth-back`
3. `cp .env.example .env`
4. Настроить переменные окружения в `.env`
5. `npm install`

## Запуск
1. Dev-mode: `npm run start:dev`
2. Сборка: `npm run build`
3. Запуск билда: `npm run start:prod`
